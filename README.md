# 🔬 Multi-Agent Research System

**🔗 [Live Demo](https://multi-agent-research-system-5lfqjtoyxmuiekyrbct4hj.streamlit.app)** · [GitHub Repo](https://github.com/ansh-pratapsingh/Multi-Agent-research-system)

A two-agent research pipeline built with LangGraph (ReAct agents) and LCEL
(Runnables) — no legacy LangChain `Chain` classes used anywhere. Ask a
research question and get back a summary grounded in real, freshly-searched
web sources.
